# SMART e-GP TOOLS Privacy Policy

Effective date: 5 August 2026

SMART e-GP TOOLS runs only on `https://www.eprocure.gov.bd/*` and provides form-filling and tender-workflow assistance requested by the user.

## Data the extension handles

- Information entered into the e-GP website, only to perform the selected tool action.
- The password entered on the e-GP login page, which is retained locally by the extension to support its existing password-fill feature.
- Activation details entered by the user: name, mobile number, address, device ID, and activation code.
- A device/browser fingerprint and installation timestamp used for licence validation.
- Settings, saved form profiles, activity values, panel preferences, and activation status, stored in the browser's local extension storage.

## How data is used and shared

The extension uses e-GP page data only to execute the feature the user selects. Activation details, the fingerprint, and installation timestamp are sent to the extension's Google Apps Script licence service to redeem or validate a licence and retrieve in-extension updates. The extension does not sell user data or use it for advertising.

The extension also opens the developer's Facebook page only when the user selects the Facebook button.

## Security and retention

Browser-stored data remains on the user's browser until the user clears extension/browser data or the extension removes it as part of licence handling. Licence-service records are retained only as needed for activation, validation, and support.
